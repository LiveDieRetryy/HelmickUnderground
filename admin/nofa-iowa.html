📥 Import NOFA Recipients from CSV

📋 How to Import

  1. Download NOFA recipient data from government sources:
    • NTIA BEAD: broadbandusa.ntia.doc.gov
    • USDA ReConnect: usda.gov/reconnect
    • FCC RDOF: fcc.gov/auction/904
  2. Export or save the data as CSV format
  3. Ensure your CSV has these columns (header names can vary):
    company_name, contact_person, email, phone, funding_amount, grant_program, award_date, address, city, county, state, zip, latitude, longitude, service_area, project_description
  4. Upload your CSV file below
